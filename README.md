# BlockingQueue Project

В этом проекте реализована упрощённая версия блокирующей очереди (`BlockingQueue`) с фиксированным размером.  
Очередь используется для обмена данными между **производителем** и **потребителем** в многопоточной среде.

Методы:
- `enqueue()` — добавляет элемент в очередь. Если очередь заполнена, поток ждёт освобождения места.
- `dequeue()` — извлекает элемент из очереди. Если очередь пуста, поток ждёт появления нового элемента.
- `size()` — возвращает текущий размер очереди.
