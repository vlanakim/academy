# Geometry Project

Мульти-модульный проект для работы с геометрическими фигурами.

Модули:
- geometry-library — 2D фигуры (Circle, Rectangle, Triangle)
- geometry-utils — утилиты (компаратор)
- three-dimensional-shapes — 3D фигуры (Cube, Sphere)
- geometry-app — демонстрационное приложение

Управление версиями:
- geometry-library начинается с 1.0.0, далее 1.1.0
- geometry-utils — SNAPSHOT (1.0.0-SNAPSHOT → 1.1.0-SNAPSHOT)
- three-dimensional-shapes — SNAPSHOT
