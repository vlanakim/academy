# Geometry Project

Проект демонстрирует использование библиотеки `geometry`,как зависимость, в приложении `geometry-app`

1. `geometry` — многомодульная библиотека для работы с геометрическими фигурами.  
   Содержит классы, интерфейсы и утилиты для вычислений.
2. `geometry-app` — обычный Maven-проект, демонстрирующий использование библиотеки `geometry` через зависимости.
