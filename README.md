# ConcurrentBank

Простой демонстрационный проект: многопоточная обработка банковских операций. 

Классы: 
- `BankAccount` — потокобезопасный банковский счёт (deposit, withdraw, getBalance), 
- `ConcurrentBank` — менеджер счетов: создание счета, атомарные переводы, получение общего баланса.
Ключевая цель — **атомарность переводов** и **избежание дедлоков** при конкурентном доступе.
